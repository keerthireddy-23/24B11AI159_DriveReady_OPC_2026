
# Day 1 - Sweet Crumbs Home Bakery Chatbot

## Objective
To create a basic AI chatbot using the Groq API.

## Technologies Used
- Python
- Google Colab
- OpenAI Python Library
- Groq API
- GPT-OSS-20B model

## Implementation
1. Installed the OpenAI Python library.
2. Retrieved the Groq API key from Google Colab Secrets.
3. Connected to Groq using the OpenAI-compatible API.
4. Created a basic chatbot that generates jokes.
5. Created a bakery chatbot using a system prompt.
6. Added bakery details, cake prices and ordering rules.
7. Displayed the model response and token usage.

## Bakery Details
- Plum Cake: Rs 500
- Chocolate Cake: Rs 650
- Cupcake: Rs 80
- Orders require 24 hours' notice.
- Eggless versions are available.

## How to Run
1. Open Google Colab.
2. Install the OpenAI library.
3. Add GROQ_API_KEY to Colab Secrets.
4. Enable notebook access to the secret.
5. Run the code.

## Learning Outcome
Learned how to connect to Groq, send prompts to an AI model and create a basic customer-support chatbot.
