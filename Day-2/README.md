
# Day 2 - Sweet Crumbs Home Bakery Chatbot using LangChain

## Objective
To improve the Day 1 bakery chatbot using LangChain and ChatGroq.

## Technologies Used
- Python
- Google Colab
- LangChain
- LangChain-Groq
- Groq API

## Implementation
1. Installed the LangChain-Groq package.
2. Retrieved the API key from Google Colab Secrets.
3. Initialized the ChatGroq model.
4. Created system, human and AI messages.
5. Added conversation history to maintain context.
6. Used llm.invoke() to generate responses.
7. Implemented a chatbot loop to interact with customers.

## Learning Outcome
Learned how to use LangChain with Groq and maintain conversation history in a chatbot.
